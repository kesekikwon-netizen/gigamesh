## R1. 화면 구조 (고정)

위에서 아래로 정확히 이 순서이며, 다른 Dock/플로팅 패널을 추가하지 않는다.

| # | 영역 | 크기 | 비고 |

| 1 | 탭 줄 | 높이 34 px, 흰 바탕 | `파일 · 홈 · ① 바닥 정하기 · 측정·탁본 · 내보내기`, 오른쪽 끝 `되돌리기/다시` |
| 2 | 타일 리본 | 최소 높이 98 px, 흰 바탕 | 그룹 이름 11 px 굵게 `Muted`, 그룹 사이 1 px `Line` 세로선 |

- **R1.1 도판이 주인공**: 실측 도판은 기본 ≥ 73 %, `Tab` 키 또는 `□` 단추로 슬롯 목록·3D 보조창을 함께 접어 **100 %**.
- **R1.2 금지**: 우측 속성 패널, 하단 측정 테이블, 20버튼 도구 팔레트 Dock, 다크 테마.
- **R1.3 치수는 띠와 풍선으로만**: 도판 머리(32 px) 아래 `치수 대장 띠`(28 px, `Wash`)에 `기고 · 구경 · 최대복경 · 저경 · 평균 기벽두께` 5대 치수를 상시 표시. 부위 치수는 도판 위 흰 모노 풍선으로.
- **R1.4 기준 배지**: 도판 머리 오른쪽에 정위치 상태 배지를 항상 둔다
  (`✓ 기준: 바닥 수평(0 mm) · 회전 중심축 정렬됨` / 미정렬 시 `Caution` 색 경고 배지, 바닥 확정 전 `▲ 바닥 미정`).

## R3. 도구 상태 3단계 (리본 타일·작은 단추·칩 공통)

1. **대기** — `Desk` 바탕, 투명 테두리 (호버 시 `Wash` + `Edge`)
2. **켜짐 토글** — `Oat` 바탕 + `Ring` 테두리 (표시 켜짐, 선택된 축척/간격 칩은 테두리 `Ink`, 굵게)
3. **손에 든 도구** — `Hand` 바탕, 흰 글자·아이콘, 이름 굵게. 동시에 하나만.

- 타일: 폭 56 px, 정사각 48×48 px, 반지름 8 px, 아이콘 24 px 단색 선(2 px, round).
- 작은 단추(`sbtn`): 높이 23 px, 반지름 6 px, 오른쪽에 단축키 `kbd` 배지.
- **주 단추(`Action`)는 리본의 `[도면]` 타일, ① 바닥 정하기의 `[이 자세로 확정]`(확정 전), 대화상자의 `[SVG / 도면 저장]`, 홈의 `[이어서 열기 →]` 처럼 화면당 하나만.**

## R4. 글꼴 (역할별 3종)

| 역할 | 글꼴 | 크기 |
|---|---|---|
| 도면·유물 제목 | 명조 `Noto Serif KR` → `Batang` (500~600) | 18–28 px |
| 모든 수치·눈금 숫자·좌표·`kbd` | 모노 `Consolas` → `JetBrains Mono` | 11–20 px, **숫자 오른쪽 맞춤, 단위 `mm`는 `Faint`** |
| 메뉴·라벨·안내 | 고딕 `Malgun Gothic` → `Noto Sans KR` | 기본 13 px |

## R5. 실측 도판 그리기 규칙

- **그리는 순서(뒤→앞)**: 방안 눈금 → 유물 음영(실사/깊이/D-Tak) → 외곽선·능선(`OuterInk`) → 단면선(`ProfileRed`).
- **눈금**: 1 mm 세선, 10 mm 주선, 50 mm마다 모노 숫자. 바닥 `H 0 mm`, 중심축 `R 0 mm` 기준.
- **회전체(토기·도자기)**: 중심축 기준 **왼쪽 = 외면(외곽선 + 문양/탁본, 먹색), 오른쪽 = 기벽 종단면(빨강 + 연한 빨강 채움)** — 국내 보고서 표준(D5, 2026-10-17 확정). `R` 로 좌/우 반전(같은 단면의 거울상 — 도판을 뒤에서 본 모양). 중심축은 먹색 실선.
- **비대칭(석기·기와·금속기)**: 정면·측면(종단면)·배면·횡단면 4면 전개를 바닥선을 맞춰 나란히.
- 축척 막대와 `구경 ⌀` 머리 치수를 도판 안에 그린다. 모든 좌표는 **실제 mm**로 유지(화면 배율만 변경).

## R6. 내보내기 규칙

- 대화상자는 좌(용지 실제 비율 미리보기 + 표제란 + 축척 막대 + 맞춤 안내) / 우(도면명·용지·축척 칩·레이어·형식) 분할.
- 축척 칩 `2:1 · 1:1(실제크기) · 1:2 · 1:3 · 1:4`, 용지 `A4 세로/가로 · A3`.
- 유물이 용지를 넘으면 `▲` 경고와 추천 축척/용지를 자동으로 띄운다.
- SVG는 **레이어 분리**: `단면선` / `외곽선·중심선` / `능선·문양` / `음영·탁본` / `방안 눈금·치수·축척` — 단위 `mm`, 1:1 실제 치수.
- DXF는 R12, mm 단위, K-Arch 11 레이어(`01_AXIS_CENTER` … `11_SCALE_BAR`).
- SVG·PDF·PNG·DXF 와 내보내기 미리보기의 좌/우는 화면 도판(R5)과 같다.

## R7. 홈(시작) 화면

- 명조 큰 제목 `동국유물실측 (DongArch3D)` + 한 줄 설명.
- `이어서 작업` 카드(유물명 명조 28 px, 경로 모노, 마지막 작업·슬롯·5대 치수·정위치 상태) + `Action` 단추 `[이어서 열기 →]`.
- `최근 실측 유물` 삼선표(위·아래 2 px `Ink`), 파일 끌어놓기 영역(`PLY · OBJ · STL`, 점선), 오른쪽 `세 걸음으로 유물 실측도 완성` 안내 카드.

## R8. 문구

- 한국어 우선, 짧은 명사형. 안내 문장은 "다음: …" 형태로 다음 할 일을 알려준다.
- 단축키는 항상 `kbd` 배지로 보여준다 (`Ctrl+O`, `S`, `Tab`, `[ ]`).
