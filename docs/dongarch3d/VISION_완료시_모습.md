## 🎯 메인 화면 구성

### 1. 메뉴 바 (완전 한국어)

```
┌─────────────────────────────────────────────────────────────────┐
│ 파일(F)  편집(E)  정렬(A)  단면(C)  외곽(O)  절단(X)  시각화(V)  파일탐색(M)  일러스트(I)  도움말(H) │
└─────────────────────────────────────────────────────────────────┘
```

**파일(F)**:
- 열기 (Ctrl+O) - PLY, OBJ, STL, GLTF
- 저장 (Ctrl+S)
- 내보내기 →
  - 3D 파일 (PLY)
  - SVG 파일 (Illustrator용)
  - PDF 보고서
- 최근 파일 (10개)
- 종료 (Alt+F4)

**정렬(A)** - Phase 1 완료:
- 회전 →
  - X축 회전
  - Y축 회전
  - Z축 회전
  - 자유 회전
- 시점 →
  - 평면도 (Top)
  - 정면도 (Front)
  - 측면도 (Right/Left)
  - 대각선 뷰 (4개)
- 원점으로 리셋

**단면(C)** - Phase 2 완료 ⭐:
- 평면도 단면 (Top Cut)
- 정면도 단면 (Front Cut)
- 측면도 단면 (Right Cut)
- 간략화 수준 (Detail Level: 0.1mm ~ 1mm)
- 곡선 피팅 (Curve Level: Low/Mid/High)
- 2D 미리보기
- Save Slot (5개)
- SVG 내보내기

**외곽(O)** - Phase 3 완료 ⭐:
- 실루엣 추출 (6방향)
- 벡터화 (Vector Tracing)
- 외곽선 두께 조정
- SVG 내보내기

**절단(X)** - Phase 4 완료:
- 평면 절단 (Clipping Plane)
- 메시 분할 (Mesh Split)
- 절단 미리보기
- 절단면 저장

**시각화(V)** - Phase 5 완료:
- X-Ray 렌더링
- D-Tak (디지털 탁본)
- 고해상도 캡처 (Tiled Capture)
- 조명 설정
- 재질 설정

**파일탐색(M)** - Phase 6 완료:
- 파일 목록 보기
- 썸네일 미리보기
- 3D 정보 (Vertices, Faces, Size)
- SVG 파일 관리

**일러스트(I)** - Phase 7 완료:
- SVG 내보내기 (1:1 스케일)
- 레이어 분리 (Cutline, Outline)
- Illustrator로 Drag & Drop
- 색상 프로파일 설정

**도움말(H)**:
- 사용자 매뉴얼 (한글)
- 튜토리얼 동영상
- 키보드 단축키
- GigaMesh 정보
- 라이선스 (GPL v3)
- DongArch3D 정보

## 🎓 사용자 시나리오 (실제 고고학 작업)

### 시나리오 1: 토기 단면도 작성

**작업 시간**: 10분 (수작업: 2시간)

1. **3D 스캔 파일 준비** (외부 작업)
   - 토기를 3D 스캐너로 스캔
   - PLY 파일 생성: `토기_A01.ply`

2. **DongArch3D 작업** (10분)
   - 파일 → 열기 → `토기_A01.ply` 로드 (3초)
   - 정렬 탭 → 평면도 시점 선택
   - 단면 탭 → "평면도 단면" 선택
   - 슬라이더로 높이 조정 (구연부, 동최대경, 저부)
   - 3개 높이에서 단면 추출:
     - Slot 1: 구연부 (200mm)
     - Slot 2: 동최대경 (125mm)
     - Slot 3: 저부 (50mm)
   - 각 Slot → SVG 내보내기

3. **Illustrator 편집** (20분)
   - 3개 SVG 파일 열기
   - 레이아웃 배치
   - 주석 추가 (치수, 문양 설명)
   - PDF 저장 → 보고서 제출

**결과**: 총 30분 (기존 2시간 → **75% 시간 단축!** 🚀)

### 시나리오 2: 석기 외곽선 추출

**작업 시간**: 5분 (수작업: 1시간)

1. **3D 스캔 파일 준비**
   - 석기 3D 스캔: `석기_B05.obj`

2. **DongArch3D 작업** (5분)
   - 파일 → 열기 → `석기_B05.obj`
   - 정렬 탭 → 평면도 시점
   - 외곽 탭 → "평면도" 선택
   - "미리보기" → 외곽선 확인
   - "SVG 내보내기" → `석기_B05_평면.svg`
   - 정렬 탭 → 정면도 시점
   - 외곽 탭 → "정면도" 선택
   - "SVG 내보내기" → `석기_B05_정면.svg`

3. **Illustrator 편집** (15분)
   - 2개 SVG 배치
   - 주석 추가
   - PDF 저장

**결과**: 총 20분 (기존 1시간 → **67% 시간 단축!**)

### 시나리오 3: 청자 디지털 탁본 제작

**작업 시간**: 3분 (수작업: 불가능)

1. **3D 스캔 파일 준비**
   - 청자 3D 스캔: `청자_C12.ply`

2. **DongArch3D 작업** (3분)
   - 파일 → 열기 → `청자_C12.ply`
   - 시각화 탭 → "D-Tak (디지털 탁본)"
   - 시작점 클릭 (문양 중심)
   - 색상 맵: Heatmap 선택
   - "계산 시작" → 2초 대기
   - "PNG 저장" → `청자_C12_탁본.png`

3. **결과물 활용**
   - 보고서에 이미지 삽입
   - 문양 분석 자료로 활용

**결과**: 3D 스캔만 있으면 즉시 디지털 탁본 제작 가능! (수작업 불가능한 작업)

### 시스템 요구사항

**최소 사양**:
- OS: Windows 10 64-bit / Ubuntu 20.04 / macOS 11+

- GPU: OpenGL 3.3 지원 (통합 그래픽 가능)
- 저장공간: 500MB (설치) + 작업 파일용 10GB

- RAM: 16GB+

- SSD: 100GB+ (빠른 파일 I/O)

### 지원 파일 형식

**입력 (Import)**:
- ✅ PLY (Binary, ASCII)
- ✅ OBJ (with MTL)
- ✅ STL (Binary, ASCII)
- ✅ GLTF 2.0

**출력 (Export)**:
- ✅ PLY (Binary, ASCII)
- ✅ SVG (Illustrator 호환)
- ✅ PDF (보고서용)
- ✅ PNG (고해상도 캡처)
