## 1. 바뀐 것 (사용자가 보는 것)
- **단면 도구(S)를 들고 3D 를 끄는 동안 오른쪽 도판의 단면과 3D 절단선이 바로 따라 바뀐다.** 끄는 동안에는 가벼운 미리보기 메시(약 2.6만 면)로 단면 한 장만 계산한다(0.7–0.8 ms). 손을 놓으면 원본으로 단면·외곽·치수·두께·음영을 모두 다시 계산한다.
- **키로 돌리기**: `←` `→` = 1°, `Shift`+`←` `→` = 15°. 기존 `,` `.` `[` `]` 와 리본 단추도 같은 방식이다 — 누르는 동안은 미리보기만, 마지막 입력 0.3초 뒤(누르고 있으면 뗀 뒤) 원본을 한 번 계산한다. 한 번의 끌기·누르기가 되돌리기 한 칸이다.
- **정면각 방향이 바뀌었다: + = 위에서 보아 반시계.** 단면 끌기·키·보는 방향 끌기가 R 반전 상태까지 모두 "가까운 면이 오른쪽으로" 돈다. JOB-004 까지와 반대 방향이다.
- 끄는 동안 그대로인 것: 외면 음영·외곽선·치수 띠·두께. 이것들은 놓은 뒤 바뀐다.
- 막 맞춤 엔진 함수(Y 막 = 0°, X 막 = 90°)를 넣었다. 단추는 JOB-006 에서 붙는다.
- 상황 줄에 `← →` · `막 1° · Shift 15°` 안내가 붙었다. 미리보기 중 내보내기는 엔진이 거부하지만, 화면은 내보내기 전에 먼저 확정하므로 사용자에게는 거부가 보이지 않는다.

## 5. 사람이 판단할 것 (좌표계·수치 알고리즘 포함)
1. **[좌표계] 정면각 방향 반전**: + = 위에서 보아 반시계(+Z 오른손 법칙), 0° = 확정 자세 그대로. 자세 회전(JOB-003)과 같은 규약이 된다. JOB-004 까지와 반대 방향이다. **실시간 단면과 같은 커밋**이라 이것만 거절하면 rework 가 된다.
2. **[좌표계] X 막 = +90° 의 뜻**: 정면에서 보아 왼쪽 옆(원래 −X 쪽)이 보는 사람을 향한다. 오른쪽 옆에서 보는 것이 맞으면 −90° 로 바꾼다.
3. **[수치] 미리보기↔원본 단면 차이**(최대 / 평균, mm):
   - 예제: 0° 2.23 / 0.18 · 12° 2.56 / 0.20 · 45° 0.89 / 0.13 · 90° 1.09 / 0.11 · 137° 0.91 / 0.12
   - 미스캔 예제: 0° 1.37 / 0.07 · 12° 0.89 / 0.05 · **45° 7.05 / 0.74** · 90° 1.02 / 0.09 · 137° 0.74 / 0.09
   - 미스캔 예제 45° 에서는 놓는 순간 단면이 눈에 띄게 바뀔 수 있다. 원인(추정 내벽 경로 차이인지 미리보기 메시 차이인지)은 아직 모른다. 대안: 미리보기 면 수를 올린다(시간 여유가 크다) 또는 미리보기에서 추정 내벽을 끈다.
4. **[수치] 미리보기의 추정 내벽**: 지금 확정된 추정 기벽 두께를 그대로 쓴다. 놓으면 다시 정하므로 추정 내벽 파선이 놓는 순간 움직일 수 있다(움직인 양은 재지 않음).
5. 끄는 동안 음영·외곽·치수·두께는 옛 각도 값이다. 3D 확대 배율도 확정 메시 기준이라 둥글지 않은 유물은 놓는 순간 확대가 조금 바뀔 수 있다. 이를 알리는 표시는 JOB-006 에서 넣는다.
6. **놓을 때 멈춤**: 원본 계산만 예제(7.7만 면) **1.36 s**, 미스캔 예제(5.2만 면) 0.93 s 다. 그 뒤 음영·3D 다시 그리기 시간은 재지 않았다. 25만 면 유물은 비례로 약 4.4 s(추정)이고 대기 커서가 없다. 끄는 중에 `Ctrl+Z`·슬롯 선택을 누르면 원본 계산이 두 번 돌아 약 2.8 s(추정). → 원본 계산을 뒤에서 돌리는 작업을 따로 할지 정해 주세요.
7. 끄는 동안 한 화면 갱신 = 단면 0.7 ms + 3D 약 15 ms + 도판 그리기(재지 않음). 16 ms 를 넘을 수 있다.
8. **내보낸 파일에 정면각·방향이 남지 않는다.** JOB-004 빌드로 같은 숫자를 넣어 만든 도판과 이번 빌드의 도판은 반대 방향 단면인데, 파일만 보고는 구별할 수 없다. 후속으로 도판에 "절단 각도 θ° (위에서 보아 반시계)"를 적는 것을 제안한다.
9. **입력 규칙**: 끄는 동안 16 ms 마다 미리보기, 키·단추는 마지막 입력 0.3초 뒤 확정, 누르고 있는 동안 보류, `Shift` 15° 는 `← →` 만. builder 가 명세의 빈틈을 메운 3곳 — 키를 누른 채 다른 동작(내보내기 등)을 하면 먼저 확정, 파일 열기에 실패하면 미리보기를 확정, `Shift`·`Ctrl` 만 누르면 확정하지 않음. 창이 포커스를 잃은 채 키를 떼면 다음 동작까지 미리보기가 남는다.
10. 리본 단추 「정면 회전 ±1°」·`.`·`]` 가 JOB-004 와 반대로 돈다. 「막」·「절단면」·「정면 회전」·「절단 위치 이동」 용어가 섞여 있다 — JOB-006 에서 원문 라벨로 정리한다.
11. 단면 도구를 들었을 때 상황 줄이 넓어졌다(약 1712 → 1847 px, 추정). 1366 px 화면에서 잘리지 않는지 확인이 필요하다.
