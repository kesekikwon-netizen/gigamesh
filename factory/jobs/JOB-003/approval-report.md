## 1. 바뀐 것 (사용자가 보는 것)
- **파일을 열면 들어온 자세 그대로** 보인다(예전에는 열자마자 자동으로 세움). 3D 창에 1 cm 방안 **바닥판(Z=0)** 이 깔리고, 도판 자리에는 "바닥을 정하기 전…" 안내와 배지 "▲ 바닥 미정"이 뜬다.
- 리본 탭 이름이 `정위치·중심축` → **`① 바닥 정하기`**. 그룹: 파일 · 바닥판에 올려놓기 [자동 세우기][X/Y/Z 90°](Shift = −90°)[뒤집기][처음 자세로][바닥에 내려놓기] · 확정 [**이 자세로 확정**](주 단추, Enter).
- 회전할 때마다 바닥판에 다시 내려앉는다. 「처음 자세로」는 열었을 때 자세로 정확히 돌아간다.
- 확정해야 단면·치수·도판이 계산된다. 확정 뒤 자세를 다시 바꾸면 확정이 풀린다.
- 예제 유물 2종과 홈의 「중심축 맞춤」은 예전처럼 자동 세우기 → 확정까지 한 번에 간다.
- 검수용 캡처 플래그 `--base`.

## 5. 사람이 판단할 것 (좌표계·수직 기준·수치 알고리즘 포함)
1. **[좌표계·수직 기준]** mm, +Z 위, 바닥판 Z=0. 확정하면 중심선을 x=y=0 으로 옮긴다(수평 외곽 원 중심 평균). 수동 확정은 회전하지 않는다 — 사람이 놓은 자세가 곧 수직.
2. **[수치·표시 위험, 정확성 검토자 추정]** 기울어진 채 확정하면 기고가 기울어진 높이로 나오고(예제 7° → 200.5 mm, 실제 184.5) 구경은 "—" 인데, 배지가 녹색 ✓로 보일 수 있다. 입이 아래인 채 확정하면 구경·저경이 뒤바뀐 채 OK 로 나올 수 있다. → 다음 조각(수평 맞추기 T/B)에서 기울기·상하 경고를 넣을지 정해 주세요.
3. **[회전 규약]** 단추 한 번 = 고정 월드축 기준 오른손 법칙 +90°, 회전 중심 = 회전 직전 바운딩 박스 중심, 회전마다 접지. 뒤집기 = X 축 180°.
4. **흐름 변화**: 파일 열기·끌어 놓기·Artec 감시 폴더 자동 열기가 모두 ① 단계에서 멈추고 Enter 확정이 한 번 더 필요하다. 확정 자세는 아직 저장되지 않아 다시 열면 다시 정해야 한다.
5. **디자인과 다른 점**: 「이 자세로 확정」이 바닥 미정이어도 늘 눌린다(확정이 접지를 겸함). 확정 뒤 자세를 바꾸면 슬롯·치수가 지워진다(디자인은 '재확인 필요·값 유지').
6. **UI 정본 변경**: UI_RULES R1 탭 이름을 바꿨다(CLAUDE.md §1 승인 대상). 목업 파일은 아직 옛 이름(백로그 8).
