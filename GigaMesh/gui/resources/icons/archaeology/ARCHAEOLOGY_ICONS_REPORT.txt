ARCHAEOLOGICAL CONTEXT
----------------------
These icons are designed for the GigaMesh Archaeological MVP project,
specifically for lithic illustration standards integration (Raczynski-Henk 2017).

Key functional groups:
- Section tools: Cross-section analysis and profile extraction
- Lithic tools: Stone tool analysis (cortex, ridges, flake scars, etc.)
- Ceramic tools: Pottery analysis (rim, body, base, decoration, etc.)
- Measurement tools: Quantitative analysis (distance, angle, area, volume, etc.)
