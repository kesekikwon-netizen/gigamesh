# MVP 개발 추적 시스템

GigaMesh 구석기 실측 규격 통합 MVP 개발을 위한 진행 추적 커맨드 시스템입니다.

## 설치된 커맨드

### 1. `/mvp-init`
MVP 진행 추적 시스템을 초기화합니다.

**기능**:
- MVP 개발 계획 파싱 (40개 Task)
- 진행 상황 파일 생성 (`.mvp-progress.json`)
- 요약 문서 생성 (`MVP_진행상황.md`)

**사용**:
```
/mvp-init
```

첫 실행 시 한 번만 실행하세요.

---

### 2. `/mvp-status`
현재 MVP 진행 상황을 확인합니다.

**기능**:
- 현재 Phase 및 Day 표시
- 진행 중인 Task 표시
- 전체 완료율 표시
- 다음 작업 제안

**사용**:
```
/mvp-status
```

### 3. `/mvp-task <action> [task_id] [notes]`
개별 Task를 관리합니다.

**Actions**:

#### `show [task_id]` - Task 상세 보기
```
/mvp-task show 1.1
```

#### `start [task_id]` - Task 시작
```
/mvp-task start 2.1
```

Task를 "in_progress"로 표시하고 시작 시간 기록

#### `complete [task_id] [notes]` - Task 완료
```
/mvp-task complete 1.1 "체크리스트 완성. 45도 규약 확인."
```

Task를 "completed"로 표시하고 완료 시간 및 노트 기록

#### `block [task_id] [reason]` - Task 블록
```
/mvp-task block 2.4 "GIMP 설치 필요"
```

#### `note [task_id] [text]` - 노트 추가
```
/mvp-task note 1.1 "페이지 23-45 특히 중요"
```

#### `next` - 다음 Task 표시
```
/mvp-task next
```

현재 Day, 의존성, Critical Path를 고려하여 다음 작업할 Task 추천

---

### 4. `/mvp-report [type]`
다양한 진행 보고서를 생성합니다.

**Report Types**:

#### `daily` (기본값)
```
/mvp-report daily
```

오늘의 진행 상황 요약

#### `phase`
```
/mvp-report phase
```

현재 Phase 요약 (완료율, 마일스톤 등)

#### `overall`
```
/mvp-report overall
```

전체 프로젝트 상태 (모든 Phase, 타임라인)

#### `timeline`
```
/mvp-report timeline
```

Gantt 스타일 타임라인

#### `acceptance`
```
/mvp-report acceptance
```

7개 Acceptance Criteria 진행 상황 (6/7 필요)

**파일로 저장**:
```
/mvp-report daily --format=markdown --output=reports/daily_20251105.md
```

---

### 5. `/mvp-agent <agent_type> [task_id]`
특화된 Sub-Agent를 실행합니다.

**Agent Types**:

#### `task-executor [task_id]`
```
/mvp-agent task-executor 1.1
```

지정된 Task를 자동으로 실행:
- Task 상세 읽기
- 필요한 파일 로드
- 단계별 실행
- Deliverable 생성
- 완료 표시

#### `plan-reader`
```
/mvp-agent plan-reader
```

MVP 계획 전체를 분석하고 구조화된 요약 제공

#### `code-analyzer`
```
/mvp-agent code-analyzer
```

GigaMesh 코드베이스 분석 (Phase 2-3용)

#### `test-runner`
```
/mvp-agent test-runner
```

테스트 실행 및 검증 (Phase 4용)

#### `phase-chain [phase_number]`
```
/mvp-agent phase-chain 1
```

전체 Phase의 Task들을 순차적으로 실행

## 팁

1. **매일 시작 시**: `/mvp-status` 실행하여 어디서부터 시작할지 확인
2. **Task 시작 전**: `/mvp-task show [id]` 로 상세 확인
3. **작업 중**: Sub-Agent 활용하여 자동화 (`/mvp-agent task-executor`)
4. **막힐 때**: `/mvp-task block [id] [reason]` 으로 블록 표시
5. **Day 종료 시**: `/mvp-report daily` 로 일일 보고서 생성
6. **Phase 전환 시**: Milestone 확인 및 GO/NO-GO 결정

## 문제 해결

### 진행 파일 손상 시
```bash
# 백업 복원
cp .mvp-progress.json.backup .mvp-progress.json

# 또는 재초기화
/mvp-init --reset
```

### Task 순서 변경 필요 시
```bash
# JSON 파일 직접 편집
nano .mvp-progress.json
# current.task_id 수정
```

### 전체 리셋
```bash
rm .mvp-progress.json
rm MVP_진행상황.md
/mvp-init
```
